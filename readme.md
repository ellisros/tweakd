## 🌐・about

**tweakd** is an independent ipa repository dedicated to tweaked, modified, and enhanced ios applications.

from customised experiences to extra features, tweakd brings a curated collection of apps together in one place.

## ✨・what's inside?

| feature | description |
|:--|:--|
| 📱 tweaked apps | customised ios applications |
| 🎨 enhanced experiences | extra features and modifications |
| 🗂️ organised listings | app icons, descriptions, and version details |
| 🔄 version history | previous releases where available |
